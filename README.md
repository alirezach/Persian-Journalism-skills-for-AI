# اسکیل‌های پژوهش و روزنامه‌نگاری فارسی

[English](README.en.md)

این مخزن ابزارها و دستورهای کاری لازم برای پژوهش و روزنامه‌نگاری فارسی را کنار هم می‌آورد: از ویرایش و ترجمه تا بررسی منبع، راستی‌آزمایی، تحلیل و بصری‌سازی داده و گزارشگری. پروژه هشت اسکیل مستقل دارد تا هرکدام مسئولیت روشنی داشته باشند و در صورت نیاز با هم کار کنند. دستور اصلی و راهنمای استفادهٔ هر هشت نوشته شده است؛ وجود راهنما با بستهٔ قابل‌نصب یا کیفیت آزموده‌شده یکی نیست.

**نسخهٔ آزمایشی: `0.4.3-editing`.** [ویرایش فارسی](skills/persian-editing/README.md) نسخهٔ `0.1.3` همراه با ابزار اختیاری تبدیل محدود ی و ک آماده است. این ابزار فقط بر بخش‌های مجاز و بازبینی‌شده عمل می‌کند؛ ویرایشگر عمومی یا تشخیص‌دهندهٔ زبان نیست. پذیرش رفتاری ناتمام است و ادامهٔ آزمون متوقف شده؛ این نسخه ادعای تأیید نهایی ندارد. [وضعیت انتشار و محدودیت‌ها](docs/evaluations/persian-editing-0.1.3-release-status.md) را بخوانید.

**ترجمهٔ علوم انسانی `0.1.0` نیز experimental است.** [راهنمای ترجمه](skills/humanities-translation/README.md) و بستهٔ مستقل آن با تصمیم صریح صاحب پروژه برای استفادهٔ آزمایشی عرضه شده‌اند؛ آزمون‌ها، ارزیابی مدل و نصب انجام نشده‌اند. [تصمیم‌نامهٔ ارتقا](docs/humanities-translation-0.1.0-experimental-decision.md) محدودیت‌ها و هش بستهٔ جدید و نامزد planned را ثبت می‌کند. شناسهٔ نسخهٔ پروژه تغییر نکرده و Release یا tag تازه‌ای ساخته نشده است.

**شش اسکیل دیگر `planned` و `source-only` هستند.** نسخهٔ منبع و نامزد مستقل همهٔ آن‌ها `0.1.1` است. شش ZIP با منابع صریح ساخته و از نظر فنی کنترل شده‌اند؛ نصب، ارزیابی رفتاری یا پذیرش ارائه نشده است. ساخت بسته به معنی اجرای بررسی منبع، تحلیل، نمودار یا گزارش واقعی نیست.

## چه چیزهایی آماده است؟

- **قواعد و قراردادها:** هفت [استاندارد مشترک](standards/) و پنج [قرارداد رکورد](schemas/README.md) برای منبع، ادعا، مجموعه‌داده، یافته و تحویل کار، همراه با یک فایل تعاریف مشترک.
- **فارسی و شیوه‌نامه:** دو [پروفایل](profiles/README.md) برای نمایش و رسم‌الخط فارسی و ترجیحات نگارشی قابل‌تغییر. این فایل‌ها تنظیمات و راهنما هستند؛ خودشان متن را بازنویسی نمی‌کنند.
- **پروندهٔ کاری:** یازده [الگوی خالی](templates/README.md)، شامل نه فرم قبلی و دو فرم تازهٔ [ماتریس شواهد](templates/evidence-matrix.csv) و [بازبینی نمایش](templates/visualization-review.md). README پوشه در این شمار نیست؛ فرم خالی یا تکمیل‌شده به‌وسیلهٔ مدل، شاهد بازبینی انسانی نیست.
- **دستورهای تخصصی:** راهنمای اصلی و README هر هشت قابلیت موجود است. اعتبارسنجی منبع راهنمای انواع مدرک دارد؛ راستی‌آزمایی نیز دو راهنمای آمار و نقل‌قول دارد. برای ترکیب پژوهش، تحلیل، بصری‌سازی و دیتاژورنالیسم قرارداد طراحی جدا نوشته شده است. وضعیت تحویل هرکدام در جدول پایین آمده است.
- **اعتبارسنج رکوردها:** [ابزار خط فرمان](scripts/validation/README.md) برای کنترل ساختار و ارجاع‌های نسخه‌دار در فایل‌های JSON. ابزار ورودی را تغییر نمی‌دهد، منابع را باز نمی‌کند و کد یا محاسبهٔ نوشته‌شده در رکورد را اجرا نمی‌کند.
- **راهنمای تخصصی تازه:** [کیفیت و اتصال داده](skills/data-analysis/references/data-quality-and-joins.md)، با مثال‌های مصنوعیِ کلید تهی، تکثیر چندبه‌چند و تغییر مخرج.

## شروع سریع

برای خواندن دستورها و محدودیت‌های هر قابلیت، از پیوند راهنمای آن در جدول وضعیت شروع کنید. شش اسکیل source-only به منابع مشترک همین مخزن ارجاع می‌دهند؛ کپی‌کردن پوشهٔ آن‌ها به‌تنهایی بستهٔ مستقل یا نصب موفق محسوب نمی‌شود. فقط مسیر لازم برای درخواست را به کار بگیرید؛ همکارهای معرفی‌شده در کاتالوگ نصب اجباری نیستند و نبود قابلیت تخصصی باید روشن گزارش شود.

اگر Node.js و وابستگی‌های لازم را دارید، از ریشهٔ مخزن این فرمان را اجرا کنید:

```bash
node scripts/validation/validate-records.cjs --input examples/records/synthetic-bundle.json
```

این [پروندهٔ نمونه](examples/records/README.md) کاملاً مصنوعی است. کد خروج صفر یعنی ورودی در کنترل‌های اجراشده رد نشده است؛ همچنان ممکن است هشدار داشته باشد. این نتیجه، صحت ادعا یا اجازهٔ انتشار را تأیید نمی‌کند.

روش آماده‌سازی وابستگی‌ها، ورودی استاندارد و محدودیت‌ها در راهنمای اعتبارسنج آمده است.

برای ساخت بستهٔ مستقل ویرایش، با Python 3.10 یا بالاتر و بدون وابستگی جانبی:

```bash
python3 scripts/packaging/build-skill.py --output dist/persian-editing-0.1.3.zip
```

برای بستهٔ آزمایشی ترجمه، سازندهٔ جداگانه را به کار ببرید:

```bash
python3 scripts/packaging/build-translation.py --output dist/humanities-translation-0.1.0-experimental.zip
```

مقصد باید تازه باشد؛ فایل موجود بازنویسی نمی‌شود. [راهنمای بسته‌بندی](scripts/packaging/README.md) منابع همراه و محدودیت‌ها را شرح می‌دهد. روش نصب هر محصول باید جدا بررسی شود. یک سازگارساز خصوصی ClickUp برای ویرایش به‌طور محدود بررسی شده است؛ جزو این مخزن نیست و گواهی سازگاری عمومی محسوب نمی‌شود. این شواهد به ترجمه یا شش اسکیل planned منتقل نمی‌شوند.

فرمان‌های بالا مربوط به مسیرهای قبلی‌اند؛ آزمون ویرایش و بسته‌های قبلی در این نوبت دوباره اجرا یا ساخته نشده‌اند. سازندهٔ تازه فقط شش نامزد planned را می‌سازد، برای نمونه:

```bash
python3 scripts/packaging/build-candidates.py --skill data-analysis --output dist/data-analysis-0.1.1-planned.zip
python3 -m unittest discover -s tests -p 'test_candidate_build.py' -v
```

این مجموعه‌آزمون فقط سازندهٔ نامزدها را می‌سنجد. نصب انجام نشده و سازنده وضعیت را خودکار ارتقا نمی‌دهد.

## قواعدی که در کار رعایت می‌کنیم

- ویرایش و ترجمه باید معنا، عدد، نقل‌قول و میزان قطعیت منبع را حفظ کنند. ترجمهٔ وفادارانه به معنی درست‌بودن ادعای نویسنده نیست.
- کیفیت شواهد را با روش، پوشش، تازگی و استقلال آن‌ها می‌سنجیم. رسمی‌بودن منبع یا تعداد بازنشرها به‌تنهایی کافی نیست.
- دادهٔ خام حفظ می‌شود. هر تغییر، محاسبه و محدودیت باید قابل‌پیگیری باشد.
- زبان فارسی، زمینهٔ ایران و سلیقهٔ نگارشی سه انتخاب جدا هستند. متن فارسی لزوماً دربارهٔ ایران نیست؛ دادهٔ ایران هم لزوماً فارسی نیست. شیوه‌نامه نباید قواعد علمی یا معنای متن را عوض کند.
- بررسی انجام‌نشده، انجام‌شده گزارش نمی‌شود. نبود ابزار، دسترسی یا شاهد باید روشن بماند.
- تماس با منابع، انتقال دادهٔ حساس و انتشار عمومی به اجازهٔ صریح نیاز دارند.

هدف، متن دقیق‌تر و کار پژوهشی قابل‌بررسی است. این پروژه نویسندهٔ متن را تشخیص نمی‌دهد و وعدهٔ عبور از ابزارهای تشخیص هوش مصنوعی نمی‌دهد.

## آزمون‌های انجام‌شده

شمارهای زیر سابقهٔ ویرایش و زیرساخت‌های آن در اجرای محلی ثبت‌شدهٔ `2026-11-14` هستند؛ شامل اسکیل یا سازندهٔ ترجمه، شش اسکیل planned و الگوها و مستندات افزوده‌شده پس از آن اجرا نیستند. برای ترجمه فقط کنترل‌های داخلی ساخت و تطبیق فایل و هش انجام شده و هیچ مجموعه‌آزمون، ارزیابی مدل یا نصب اجرا نشده است.

در بررسی نامزد ثابت ۰.۱.۳، پیش از جمع‌بندی انتشار، **۳۳۸ آزمون گذشت و هیچ‌کدام شکست نخورد**. آزمون تازه‌ای در آماده‌سازی انتشار اجرا نشد:

- ۶۷ آزمون قرارداد و بازگشت؛
- ۸۸ آزمون اعتبارسنج و خط فرمان؛
- ۳۲ آزمون پروفایل و الگو؛
- ۲۰ کنترل ساختاری اسکیل و سناریوها؛
- ۱۶ کنترل ساختاری قواعد و منابع ویراستاری؛
- ۴۱ آزمون سازندهٔ بسته؛
- ۷۴ آزمون ابزار تبدیل محدود، شامل رگرسیون دو شکست قبلی و ورودی‌های نامعتبر.

[گزارش نسخهٔ 0.1.3](docs/evaluations/persian-editing-0.1.3.md) دامنهٔ همان بررسی تاریخی را ثبت می‌کند. [رکورد تکمیلی 0.1.2](docs/evaluations/persian-editing-0.1.2-astra-opus-2026-11-14.md) اجرای بعدی پایلوت، دو نقص اجرایی و بازآزمایی Astra با داوری Opus را جدا شرح می‌دهد. قبولی آن پاسخ‌های شناخته‌شده، رفع نقص اسکیل یا تأیید نسخهٔ جدید نیست.

محیط اجرا: Node.js `v22.23.1`، Ajv `6.15.0`، js-yaml `4.3.2` و Python `3.12.13`. این آزمون‌ها ساختار، روابط رکوردها و رفتار کد را می‌سنجند؛ کیفیت ویرایش مدل را ثابت نمی‌کنند. مجموعهٔ تاریخی E01 تا E12 دست‌نخورده مانده است. [گزارش ارزیابی ویرایش 0.1.1](docs/evaluations/persian-editing-0.1.1.md) بازآزمایی H01 تا H03 با سه تکرار برای هر شرط و محدودیت‌های آن را جدا ثبت می‌کند؛ این موارد برای نویسندهٔ اسکیل شناخته‌شده‌اند، نه دادهٔ مستقل انسانی.

نصب شبکه‌ای وابستگی‌ها، فرمان‌های npm، خط CI، نمایش واقعی RTL و ممیزی امنیتی جامع هنوز آزموده یا اجرا نشده‌اند. نصب خصوصی و یک اجرای بومی بررسی محدود دارند؛ خط مبنای معتبر و پذیرش کامل حاصل نشده است. [جمع‌بندی انتشار](docs/evaluations/persian-editing-0.1.3-release-status.md) از گزارش‌های قدیمی‌تر جداست. فایل قفل کامل وابستگی‌های فرعی هم وجود ندارد.

برای شش نامزد planned، در اجرای جداگانهٔ `2026-11-16`، **۴۰ آزمون واحد سازنده گذشت**؛ فایل‌ها و هش‌های شش ZIP تطبیق داده شدند و ساخت تکراری در همان محیط بایت‌های یکسان داد. [گزارش فنی](docs/evaluations/six-skills-0.1.1-technical.md) دامنه، هش‌ها و محدودیت‌ها را ثبت می‌کند. این اعداد به شمار تاریخی ویرایش اضافه نمی‌شوند.

۱۸ سناریوی رفتاری، سه مورد برای هر اسکیل، آماده‌اند ولی اجرا نشده‌اند. ارزیابی رفتاری، داوری مستقل، بازبینی انسانی، نصب، اعتبارسنج رسمی Agent Skills و سازگاری میزبان انجام نشده‌اند. کنترل فنی بسته شاهد پذیرش اسکیل نیست و کنترل ضروری تحلیل، نمودار یا گزارش واقعی همچنان لازم است.

## نقش مدل در ساخت و ارزیابی

این مخزن با مدل **GPT 6 Astra** ایجاد شده و ارزیابی اولیهٔ مستندات و کد آن نیز با همین مدل انجام شده است. مدل در طراحی ساختار، نگارش و بازنویسی مستندات، تولید کد و طراحی آزمون‌ها به کار رفته است.

این بازبینی، ارزیابی مستقل از فرایند تولید نیست. آزمون‌های نرم‌افزاری در Node.js و Python و مقایسه‌های محدود خروجی مدل جدا ثبت می‌شوند. مدل دقیق زیرعامل‌های دورهای قدیمی تأیید نشده است. در دور تازهٔ 0.1.2، نام Astra از اعلان محیط و نام Opus از اظهار داور دربارهٔ اعلان محیط ثبت شد؛ رسید API وجود ندارد. آن دور آگاه از معیارها و با کورسازی ناقص بود. بازنگری 0.1.3 نیز با Astra تهیه شده است؛ یک اجرای مستقیم با نام اعلام‌شدهٔ Astra ثبت شده، اما پذیرش رفتاری کامل و تأیید انسانی ندارد. استفاده از مدل به معنی تأیید پروژه از سوی سازندهٔ آن نیست.

نگارش دستورهای تازه با مدل، اجرای آزمایشی یا ارزیابی رفتاری همان اسکیل‌ها محسوب نمی‌شود؛ وضعیت هر بررسی جدا در کاتالوگ ثبت شده است.

- [jamditis/claude-skills-journalism](https://github.com/jamditis/claude-skills-journalism): به‌ویژه بخش `journalism-core` و اسکیل `data-journalism`، برای ثبت منشأ، دفتر ادعا، حفظ دادهٔ خام، روش‌شناسی عمومی و جداسازی مسئولیت‌ها.

برای طراحی قالب بسته‌ها نیز از [استاندارد Agent Skills](https://agentskills.io/specification) استفاده شده است. این ارجاع‌ها گواهی سازگاری یا تأیید همهٔ قواعد و نمونه‌کدهای آن پروژه‌ها نیستند.

کد، قلم، فرهنگ واژگان، داده و تصویر آن مخزن‌ها همراه این پروژه بازتوزیع نشده‌اند. جزئیات نسخه‌های بررسی‌شده، وابستگی‌ها و مجوزها در [اعلان منابع ثالث](THIRD_PARTY_NOTICES.md) آمده است. منبع تخصصی ACLS و نشانی دقیق منابع مشترک ترجمه نیز در [اعلان مخصوص بستهٔ ترجمه](skills/humanities-translation/package-NOTICES.md) ثبت‌اند؛ حقوق آن‌ها به MIT تبدیل نشده است.
