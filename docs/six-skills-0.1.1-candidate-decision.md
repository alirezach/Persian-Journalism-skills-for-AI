# تصمیم آماده‌سازی شش نامزد مستقل

تاریخ: `2026-11-16`  
نسخهٔ منبع: `0.1.1`  
وضعیت: `planned`  
پیاده‌سازی اسکیل‌ها: `source-only`

صاحب پروژه آماده‌سازی منابع تخصصی لازم، شش بستهٔ مستقل، آزمون‌های فنی مرتبط و سناریوهای ارزیابی را تأیید کرده است. گزینهٔ انتخاب‌شده صریحاً **بدون نصب در ClickUp** بود. این تصمیم اجازهٔ ایجاد Release یا tag، ارتقای چرخهٔ عمر، تغییر اسکیل‌های نصب‌شده یا ازسرگیری ارزیابی قدیمی ویرایش نیست.

## دامنه

۴۷ مسیر مخزن: ۲۶ فایل تازه و ۲۱ به‌روزرسانی. سه منبع تخصصی تازه: ماتریس شواهد، راهنمای کیفیت و اتصال داده و فرم بازبینی نمایش. دو فرم تازه شمار الگوهای کاری را به ۱۱ می‌رسانند؛ راهنما و README الگوی کاری شمرده نمی‌شوند.

نامزدها: `source-verification`، `fact-checking`، `research-synthesis`، `data-analysis`، `data-visualization` و `data-journalism`.

برای هر نامزد، فهرست صریح منابع، README بسته و اعلان مجوز جدا نگهداری می‌شود. سازندهٔ تازه فقط همین شش اسکیل را با وضعیت planned می‌پذیرد. سازنده‌ها و بسته‌های ویرایش و ترجمه، schemaها و گزارش‌های تاریخی تغییر نمی‌کنند. نسخهٔ پروژه همچنان `0.4.3-editing` است؛ نسخهٔ نامزدها به معنی انتشار پروژهٔ تازه نیست.

## مبنا و بازتولید

مبنای قبل از تغییر commit `2ae2ce4025a4bdff9941d59e8853da30623e7c65` است. فایل‌های تغییرکرده محتوای همان commit نیستند؛ manifest خروجی هش واقعی هر ورودی، خروجی و سازنده را ثبت می‌کند. نام نسخه به‌تنهایی شناسهٔ محتوای بسته نیست.

فقط منابع صریح عمومی وارد ZIP می‌شوند، نه همهٔ مخزن. منابع ضروری همراه بسته‌اند. پیوندهای نقش همکار یا زمینهٔ مخزن که همراه نیستند، به نسخهٔ مبنای مخزن اشاره می‌کنند؛ آن‌ها نصب یا اجرای همکار را تضمین نمی‌کنند. استفاده بدون قابلیت تخصصی باید محدودیت خود را اعلام کند.

ساخت فایل‌های منبع را بازنویسی نمی‌کند. هر ZIP مقصد تازه و هش مستقل دارد. نسخه‌های ۰.۱.۰ در تاریخچه محفوظ‌اند؛ بسته‌های پیشین و شواهد ناموفق حذف یا بازنام‌گذاری نمی‌شوند.

## مرز شواهد

- آزمون واحد سازنده فقط رفتارهای فنی مشخص روی ورودی مصنوعی را می‌سنجد.
- کنترل ZIP واقعی شامل فایل، هش، منابع، پیوندها و تکرار ساخت در محیط ثبت‌شده است.
- سناریوی رفتاری تا پیش از ثبت اجرا و خروجی، آزمون انجام‌شده نیست.
- بارگذاری، فعال‌سازی و رفتار میزبان شواهد جدا لازم دارند؛ در این تصمیم نصب انجام نمی‌شود.
- بازبینی نویسنده یا تیک مدل، داوری مستقل یا انسانی نیست.

نتیجه‌های واقعی در [گزارش فنی نامزدها](evaluations/six-skills-0.1.1-technical.md) ثبت می‌شوند. شمار تاریخی ۳۳۸ آزمون ویرایش به این نسخه‌ها منتقل نمی‌شود. مقایسهٔ با اسکیل و بدون اسکیل فقط با جداسازی واقعی شرایط معتبر است؛ نام عامل، هویت تأییدشدهٔ مدل را ثابت نمی‌کند.

## تصمیم انتشار بعدی

ساخت موفق برای ارتقای خودکار کافی نیست. تصمیم بعدی باید بسته و هش دقیق، منابع و مجوزها، نتایج واقعی و محدودیت‌های باز، میزبان و صاحب اختیار را مشخص کند.

در این مرحله ارتقا به experimental یا tested، ایجاد Release و tag، نصب یا جایگزینی اسکیل خصوصی انجام نمی‌شود. اجرای پروندهٔ واقعی، تماس با منبع یا انتشار گزارش نیز در دامنه نیست. ثبت این منابع عمومی و تحویل ZIP، مجوز انتشار دادهٔ محرمانهٔ پرونده‌های آینده نیست.
