## محیط و فرمان‌های اجراشده

- Node 24.22.1، Python 3.13.18، npm 12.2.3.
- Ajv 6.15.0 و js-yaml 4.3.2، بدون تغییر نسخهٔ وابستگی‌های مستقیم.
- lockfile نسخهٔ ۳، شامل ۸ بستهٔ npm با نسخه، نشانی registry و integrity.
- اجرای جداگانه در محیط Linux؛ این گزارش ادعای اجرای ماتریس چندسیستم‌عاملی یا محیط GitHub-hosted ندارد.

```bash
npm install --package-lock-only --include=dev --ignore-scripts --no-audit --no-fund
npm ci --include=dev --ignore-scripts --no-audit --no-fund
npm test
npm --prefix tests test
```

پس از نصب پاک دوم، آزمون کامل دوباره موفق بود و بایت‌های lockfile تغییر نکرد. اجرای سازگار و تکرارها به مجموع ۵۰۵ افزوده نمی‌شوند. اجرای مستقیم normalization جداگانه لازم نیست؛ کشف Python آن را یک بار اجرا می‌کند.

## چه چیزی واقعاً ساخته شد؟

ده مهارت از منابع جاری، با سازنده‌های واقعی و از طریق CLI ساخته شدند: ویرایش، ترجمه، شش نامزد، دیتاکس و ترکیبی. همچنین مسیر ویرایش در سازندهٔ مجموعه، بستهٔ هشت‌مهارتی کامل و انتخاب ترجمه/تحلیل، مجموعهٔ سه‌مهارتی و انتخاب ترکیبی، و دو قالب فرمان سازگار قدیمی ساخته شدند. در مجموع ۱۷ مسیر ساخت، هرکدام دوباره ساخته و از نظر بایت‌های ZIP مقایسه شدند؛ این زیرحالت‌ها آزمون‌های جداگانه به شمار کل اضافه نمی‌کنند.

کنترل‌ها شامل هش منابع و خروجی manifest، اندازه و تعداد فایل، نام‌های امن و یکتا، metadata ثابت ZIP، پیوندهای محلی در قرارداد هر بسته، و برابری کامل دو جزء تعبیه‌شده با بستهٔ مستقل است. منابع ساخت واقعی mock نشده‌اند. آزمون‌های قدیمی مصنوعی همچنان برای خطاهای مرزی باقی‌اند.

برای ترجمه، جلوگیری از بازنویسی فایل موجود، شکست در منبع مفقود و پیوند خارج از بسته نیز اجرا شد. تمام خروجی‌ها در مسیر موقت ساخته و پاک می‌شوند؛ بستهٔ انتشار تازه یا نصب میزبان انجام نشده است.

## شکست آزمایشی و اصلاح فرض آزمون

دو کنترل جدا از شمار ۵۰۵، فایل شکست عمدی JavaScript و Python را موقتاً افزودند. هر دو بار سایر مجموعه‌ها اجرا شدند و فرمان نهایی ناموفق ماند؛ فایل‌های موقت حذف شدند. این شکست‌های عمدی رگرسیون محصول نیستند.

اجرای مقدماتی دو ناسازگاری داشت: قرارداد قدیمی نام مستقیم مجموعه در فرمان npm را می‌خواست؛ و آزمون تازه، مسیرهای دیتاکس را برخلاف قرارداد ریشهٔ مهارت نسبت به فایل راهنما می‌سنجید. قرارداد اتصال اجراکننده حفظ و به مسیر جدید وصل شد؛ فرض آزمون لینک با قرارداد مستند بسته هماهنگ شد. هیچ منبع مهارت یا سازنده برای سبزکردن آزمون تغییر نکرد.

## CI و موارد تأییدنشده

[workflow](../../.github/workflows/test.yml) نصب از lockfile و همین `npm test` را برای main و PRهای آن تعریف می‌کند. محیط انتخابی Ubuntu 24.04 با نسخه‌های دقیق بالا است. سه Action رسمی به SHA کامل بسته شده‌اند، مجوز محتوا فقط خواندنی است، credential باقی نمی‌ماند و job انتشار یا استقرار وجود ندارد. پس از آزمون تغییر فایل‌های tracked بررسی می‌شود.

هنگام ثبت این گزارش، اجرای hosted CI هنوز مبنای نتیجه نبود. نتیجه و URL هر اجرای GitHub باید جدا بررسی شود. تست YAML اثبات اجرای واقعی workflow نیست. این تغییر سیاست branch protection یا mandatory checks را تنظیم نمی‌کند.

قفل npm کل سیستم‌عامل و ابزارهای سیستمی را ثابت نمی‌کند. URL بیرونی، نمایش RTL، عنوان لنگر Markdown، رفتار مدل، نصب OpenCode، پوشش خط/شاخه و ممیزی جامع امنیتی بررسی نشده‌اند. هیچ نسخه یا وضعیت planned/experimental ارتقا پیدا نمی‌کند. [راهبرد آزمون](../testing-strategy.md)
