# گزارش فنی بستهٔ OpenCode ۰.۱.۰

تاریخ: 2026-11-16. مبنای پیش از این مرحله: `748606b537f840609b78ec344e1488d301cf86d9`. دامنهٔ مصوب: ۱۳ فایل مخزن، شامل ۸ به‌روزرسانی و ۵ فایل تازه؛ ساخت بسته و آزمون فنی، بدون نصب میزبان، ارزیابی رفتاری، ارتقای مهارت، Release یا tag.

## نتیجه

بستهٔ کامل هشت‌مهارتی و بستهٔ انتخابی ویرایش/تحلیل داده ساخته شدند. هر دو ZIP از نظر CRC، فهرست دقیق فایل‌ها، اندازه/هش خروجی، برابری بایت‌های مهارت با خروجی سازندهٔ کانونی و تکرار ساخت در همان محیط بررسی شدند. هر دو ساخت تکراری بایت‌های یکسان دادند.

این نتیجه بررسی نرم‌افزار و آرشیو است؛ OpenCode نصب یا اجرا نشده، مدل فراخوانی نشده و کیفیت مهارت‌ها یا کنترل دسترسی میزبان آزموده نشده است.

محیط: Python 3.12.13، Node v22.23.1، js-yaml 4.3.2 و محیط Linux موجود؛ وابستگی‌ها از پیش نصب بودند. آزمون‌های Node مستقیم اجرا شدند، نه با npm. کل مجموعهٔ مخزن اجرا نشد؛ schema/validator، helper رونویسی، CI، نصب شبکه‌ای و ارزیابی مدل در این اجرا نبودند. ۳۳۸ کنترل تاریخی ویرایش یا ۱۸ سناریوی آمادهٔ شش مهارت، نتیجهٔ تازهٔ این مرحله محسوب نمی‌شوند.

پیش از این مرحله، سه آزمون قدیمی در commit مبنا اصلاح شدند: ۱۱ فرم واقعی با README مستندات تفکیک شد و دو آزمون ویرایش از تعداد مهارت‌های planned نامرتبط مستقل شدند. ۶۸ کنترل آن سه مجموعه در مرحلهٔ اصلاح گذشت و اینجا دوباره در شش مجموعهٔ بالا آمده است؛ جمع‌زدن دوبارهٔ ۶۸ نادرست است.

## کنترل‌ها و حدود

- منابع گردآوری‌شده پیش از ویرایش با Git blob مبنا تطبیق داده شدند؛ چند اختلاف انتقال اصلاح شد و ورودی نامنطبق برای ساخت نهایی استفاده نشد.
- سازنده فقط کد سازنده‌های کانونیِ checkout مورداعتماد را import می‌کند؛ اسکریپت همراه مهارت، مدل یا OpenCode اجرا نمی‌شود. cache بایت‌کد سازنده‌های importشده در مسیر ساخت غیرفعال است.
- نام/نسخه/وضعیت، manifest، فایل‌های همراه و هش‌ها کنترل می‌شوند. symlink، مسیر غیرمجاز، برخورد نام یا فایل/پوشه، متن نامعتبر UTF-8 و اندازه/شمار بیش از حدود رد می‌شوند. خروجی موجود بازنویسی نمی‌شود.
- روش حل پیوند هر سازندهٔ قدیمی حفظ شده است؛ این parser عمومی Markdown/YAML یا اعتبارسنج رسمی Agent Skills نیست. پیوندهای وب، fragment و JSON Pointer دوباره تأیید نشده‌اند.
- این ابزار اسکن اسرار، ممیزی حقوقی، sandbox یا نصب‌کننده نیست. اعتبار هش، اعتماد به کد یا مجوز انتشار ایجاد نمی‌کند؛ race فایل‌سیستم خارج از تضمین است.
- هیچ AGENTS.md، تنظیمات permission/model، کلید حساب یا پیکربندی سرویس تولید/جایگزین نمی‌شود. محلی‌بودن بسته، محرمانگی مدل ابری را تضمین نمی‌کند.

## موارد اجرا‌نشده و گام بعد
