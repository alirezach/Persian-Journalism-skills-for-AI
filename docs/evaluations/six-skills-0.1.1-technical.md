برای هر شش بسته، خوانایی ZIP، فهرست دقیق ورودی و خروجی، هش فایل مبدأ و فایل بازنویسی‌شده، metadata دستور اصلی، وجود مقصد پیوندهای محلی و ساخت مجدد با همین سازنده بررسی شدند. نتیجهٔ ساخت مجدد با آرشیو اولیه مقایسهٔ بایتی شد؛ هیچ تفاوتی نداشت.

- `data-journalism`: 24 منبع با هش ورودی و خروجی؛ 41 ارجاع محلی Markdown به فایل موجود حل شد.

شمار پیوندها تعداد ارجاع‌هاست، نه تعداد منابع مستقل یا اعتبار محتوا. منابع تخصصی لازم داخل بسته‌اند؛ پیوندهای اعلام‌شده به نقش همکار یا زمینهٔ مخزن، بیرونی و به نسخهٔ مبنا مقیدند. این پیوندها نصب همکار را ایجاد نمی‌کنند و ممکن است وضعیت پیش از آماده‌سازی نامزد را توضیح دهند.

کنترل metadata محدود به قالب همین پروژه است. parser کامل Markdown یا YAML، اعتبارسنج رسمی Agent Skills، صحت لنگرهای عنوان، اجزای JSON Pointer و بازشدن یا اعتبار نشانی‌های بیرونی بررسی نشده‌اند. وجود schema همراه، اجرای اعتبارسنج رکورد، درستی محاسبه یا حقیقت ادعا را ثابت نمی‌کند.
