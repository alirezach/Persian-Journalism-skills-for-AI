# ساخت بستهٔ مستقل ویرایش فارسی

این سازنده فقط `persian-editing` را بسته‌بندی می‌کند، نه همهٔ اسکیل‌های آینده. Python 3.10 یا بالاتر و کتابخانهٔ استاندارد کافی است؛ نصب شبکه‌ای ندارد. نسخهٔ آزموده‌شده در گزارش ارزیابی ثبت می‌شود.

از ریشهٔ مخزن:

```bash
python3 scripts/packaging/build-skill.py --help
python3 scripts/packaging/build-skill.py --output dist/persian-editing-0.1.3.zip
python3 tests/test_editing_build.py
node tests/editing-package.test.cjs
```

فرمان آخر به js-yaml مشخص‌شده در package.json نیاز دارد. ساخت ZIP به Node، مدل یا کتابخانهٔ جانبی نیاز ندارد. کد خروج سازنده: صفر برای ساخت موفق، ۲ برای ورودی/ساخت ناموفق. گزارش موفقیت JSON روی stdout و خطای محدود روی stderr است. ورودی تعاملی ندارد و فایل موجود را بازنویسی نمی‌کند؛ برای ساخت مجدد مقصد تازه بدهید.

## چه چیزی وارد بسته می‌شود؟

فقط فایل‌های صریحاً فهرست‌شده در `skills/persian-editing/build-manifest.json`: دستور اصلی، پنج راهنمای ویرایش، چهار استاندارد مشترک، دو پروفایل، یک ابزار Python اختیاری، مجوز و اعلان منابع. یک manifest خروجی نیز ساخته می‌شود؛ مجموع ۱۶ فایل. منبع هر فایل و SHA-256 قبل و بعد از بازنویسی مسیر ثبت می‌شود. خود manifest هش خودش را ندارد. شناسهٔ commit از محیط حدس زده نمی‌شود؛ هش فایل‌ها و سازنده مبنای بازتولیدند.

مسیر منابع مشترک فقط در پیوندهای مشخص دستور اصلی بازنویسی می‌شود. فایل منبع دست‌نخورده می‌ماند. منابع مشترک در مخزن یک نسخه دارند؛ کپی داخل ZIP تولیدشده است. بایت‌های ZIP با محتوای یکسان در محیط آزموده‌شده تکرارپذیرند: ترتیب، زمان و مجوز ثابت و بدون فشرده‌سازی. بازتولید بین نسخه‌های متفاوت Python یا سیستم‌عامل‌ها هنوز آزموده نشده است.

## حدود کنترل

مسیر مطلق، پیمایش `..`، مسیر ویندوزی، symlink منبع و مقصد، نام تکراری، فایل غیرعادی، خروجی موجود و پیوند محلی حل‌نشده رد می‌شوند. ورودی هر فایل حداکثر ۱ MiB و مجموع فایل‌های بسته ۴ MiB است؛ حداکثر ۳۲ فایل منبع. فایل‌های UTF-8 از نواحی عمومیِ مجاز انتخاب می‌شوند، نه با پیمایش تمام مخزن.

بررسی پیوند محدود به نحو سادهٔ Markdown پروژه است؛ parser کامل Markdown، HTML یا اعتبارسنج لنگرهای عنوان نیست. پیوند وب باز نمی‌شود. اعتبارسنج رسمی `skills-ref` اجرا نشده است. metadata با آزمون‌های محلی بررسی می‌شود؛ سازنده به‌تنهایی اعتبار معنایی دستور یا کامل‌بودن همهٔ قواعد را تضمین نمی‌کند.

کد، manifest و checkout باید مورداعتماد باشند. این ابزار sandbox، ضد‌بدافزار، اسکن اسرار، ناشناس‌ساز یا ابزار صدور مجوز انتشار نیست. مجازبودن مسیر مانع وجود متن حساس در همان فایل نمی‌شود. تغییر هم‌زمان فایل‌سیستم و ورودی خصمانه خارج از دامنهٔ تضمین است. کنترل symlink محدودیت شبکه‌فایل‌سیستم یا مرز امنیتی سیستم‌عامل ایجاد نمی‌کند.

مقدار `model_evaluation: not_run` در گزارش سازنده فقط می‌گوید خودِ عملیات ساخت مدل را اجرا نکرده است؛ سابقهٔ جداگانهٔ ارزیابی هر نسخه در کاتالوگ و پروندهٔ ارزیابی آمده است.

نصب در محصول، فراخوانی مدل، ذخیرهٔ متن واقعی کاربران و انتشار GitHub جزو عملیات سازنده نیست. ابزار تبدیل فقط از مسیر دقیق `scripts/editing/normalize_transcribed_fa.py` به `scripts/normalize_transcribed_fa.py` بسته‌بندی می‌شود؛ مجوز عمومی ورود فایل Python اضافه نشده است. سازنده هیچ فایل Python بسته را هنگام ساخت اجرا نمی‌کند و خودش همراه بسته توزیع نمی‌شود. اجرای آزمایشی ابزار پس از استخراج، آزمون نصب در یک محصول نیست.

## سازندهٔ جداگانهٔ ترجمه، وضعیت planned

بخش‌های بالا مخصوص سازندهٔ ویرایش و سابقهٔ آن‌اند. فایل `build-skill.py` تغییر نکرده است. سازندهٔ جدید `build-translation.py` فقط بستهٔ نامزد ترجمه را می‌سازد؛ سازندهٔ عمومی همهٔ اسکیل‌ها نیست.

```bash
python3 scripts/packaging/build-translation.py --output dist/humanities-translation-0.1.0-planned.zip
```

Python 3.10+ و کتابخانهٔ استاندارد کافی‌اند. ۱۴ منبع مجاز در `skills/humanities-translation/build-manifest.json` صریح‌اند؛ خروجی همراه `manifest.json` مجموعاً ۱۵ فایل است. README و اعلان منابع از دو متن مخصوص بسته تولید می‌شوند. مسیر پیوندها در تمام فایل‌های Markdown، از جمله راهنماهای فرعی، نسبت به محل همان فایل حل و به مقصد داخل بسته بازنویسی می‌شود؛ شیوهٔ حل مسیر با سازندهٔ قدیمی ویرایش یکی فرض نشود.

سازنده نام‌ها، محدودهٔ مسیر، نبود symlink، اندازه، UTF-8، وضعیت planned و نسخهٔ دستور اصلی را کنترل می‌کند. فهرست ورودی با فهرست محدود داخل کد تطبیق دارد. ورودی هر فایل حداکثر ۱ MiB و مجموع ۴ MiB است. خروجی موجود بازنویسی نمی‌شود. کد خروج صفر برای ساخت موفق و ۲ برای خطای ورودی یا ساخت است. هیچ فایل منبعی تغییر نمی‌کند.

کنترل پیوند فقط نحو سادهٔ inline Markdown را پوشش می‌دهد؛ HTML، reference links و نحو پیچیده پشتیبانی نمی‌شوند. پیوند محلی خروجی باید داخل بسته حل شود. لنگر عنوان و نشانی خارجی بررسی نمی‌شوند. metadata با الگوی محدود متنی بررسی می‌شود، نه parser عمومی YAML. کد جدید، اسکن امنیتی یا ممیزی مجوز انجام نمی‌دهد و در برابر تغییر هم‌زمان فایل‌سیستم تضمین ندارد.

manifest شامل هش سازنده، پیکربندی، ورودی و خروجی فایل‌ها و تغییر پیوندهاست؛ هش خودش را ثبت نمی‌کند. baseline_revision نسخهٔ مبنای پیش از اضافه‌شدن فایل‌های بسته‌بندی است و برای تمام ورودی‌ها ادعای commit مشترک نمی‌سازد. زمان، ترتیب و مجوز ZIP ثابت‌اند، اما بازتولید بین محیط‌ها یا نسخه‌های Python آزموده نشده است.

در آماده‌سازی 2026-11-15 فقط ساخت نامزد و تطبیق محتویات و هش‌های آرشیو انجام شد؛ هیچ مجموعه‌آزمون پروژه، ارزیابی مدل یا نصب اجرا نشد. فرمان‌های آزمونِ بخش ویرایش، سابقهٔ همان ابزارند و دستور اجرای این مرحله نیستند. نتیجهٔ ساخت، وضعیت planned را تغییر نمی‌دهد؛ Release و tag نیز ساخته نمی‌شوند.
