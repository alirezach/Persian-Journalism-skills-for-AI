# ساخت بستهٔ مستقل ویرایش فارسی

این سازنده فقط `persian-editing` را بسته‌بندی می‌کند، نه همهٔ اسکیل‌های آینده. Python 3.10 یا بالاتر و کتابخانهٔ استاندارد کافی است؛ نصب شبکه‌ای ندارد. نسخهٔ آزموده‌شده در گزارش ارزیابی ثبت می‌شود.

از ریشهٔ مخزن:

```bash
python3 scripts/packaging/build-skill.py --help
python3 scripts/packaging/build-skill.py --output dist/persian-editing-0.1.0.zip
python3 tests/test_editing_build.py
node tests/editing-package.test.cjs
```

فرمان آخر به js-yaml مشخص‌شده در package.json نیاز دارد. ساخت ZIP به Node، مدل یا کتابخانهٔ جانبی نیاز ندارد. کد خروج سازنده: صفر برای ساخت موفق، ۲ برای ورودی/ساخت ناموفق. گزارش موفقیت JSON روی stdout و خطای محدود روی stderr است. ورودی تعاملی ندارد و فایل موجود را بازنویسی نمی‌کند؛ برای ساخت مجدد مقصد تازه بدهید.

## چه چیزی وارد بسته می‌شود؟

فقط فایل‌های صریحاً فهرست‌شده در `skills/persian-editing/build-manifest.json`: دستور اصلی، چهار راهنمای ویرایش، سه استاندارد مشترک، دو پروفایل و مجوز و اعلان منابع. یک manifest خروجی نیز ساخته می‌شود. منبع هر فایل و SHA-256 قبل و بعد از بازنویسی مسیر ثبت می‌شود. خود manifest هش خودش را ندارد. شناسهٔ commit از محیط حدس زده نمی‌شود؛ هش فایل‌ها و سازنده مبنای بازتولیدند.

مسیر منابع مشترک فقط در پیوندهای مشخص دستور اصلی بازنویسی می‌شود. فایل منبع دست‌نخورده می‌ماند. منابع مشترک در مخزن یک نسخه دارند؛ کپی داخل ZIP تولیدشده است. بایت‌های ZIP با محتوای یکسان در محیط آزموده‌شده تکرارپذیرند: ترتیب، زمان و مجوز ثابت و بدون فشرده‌سازی. بازتولید بین نسخه‌های متفاوت Python یا سیستم‌عامل‌ها هنوز آزموده نشده است.

## حدود کنترل

مسیر مطلق، پیمایش `..`، مسیر ویندوزی، symlink منبع و مقصد، نام تکراری، فایل غیرعادی، خروجی موجود و پیوند محلی حل‌نشده رد می‌شوند. ورودی هر فایل حداکثر ۱ MiB و مجموع فایل‌های بسته ۴ MiB است؛ حداکثر ۳۲ فایل منبع. فایل‌های UTF-8 از نواحی عمومیِ مجاز انتخاب می‌شوند، نه با پیمایش تمام مخزن.

بررسی پیوند محدود به نحو سادهٔ Markdown پروژه است؛ parser کامل Markdown، HTML یا اعتبارسنج لنگرهای عنوان نیست. پیوند وب باز نمی‌شود. اعتبارسنج رسمی `skills-ref` اجرا نشده است. metadata با آزمون‌های محلی بررسی می‌شود؛ سازنده به‌تنهایی اعتبار معنایی دستور یا کامل‌بودن همهٔ قواعد را تضمین نمی‌کند.

کد، manifest و checkout باید مورداعتماد باشند. این ابزار sandbox، ضد‌بدافزار، اسکن اسرار، ناشناس‌ساز یا ابزار صدور مجوز انتشار نیست. مجازبودن مسیر مانع وجود متن حساس در همان فایل نمی‌شود. تغییر هم‌زمان فایل‌سیستم و ورودی خصمانه خارج از دامنهٔ تضمین است. کنترل symlink محدودیت شبکه‌فایل‌سیستم یا مرز امنیتی سیستم‌عامل ایجاد نمی‌کند.

نصب در محصول، فراخوانی مدل، ذخیرهٔ متن واقعی کاربران و انتشار GitHub جزو عملیات سازنده نیست. بستهٔ خروجی فقط دستور و منابع متنی دارد و اسکریپت سازنده همراه آن توزیع نمی‌شود.
