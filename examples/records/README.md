# پروندهٔ کاملاً مصنوعی

`synthetic-bundle.json` یک آرایهٔ پنج‌عضوی از رکورد منبع، مجموعه‌داده، یافته، ادعا و تحویل است. مقدارهای ۱۰ و ۲۰ و میانگین ۱۵ صرفاً برای آزمون‌اند؛ هیچ شاهد، ناشر، بازبین یا تصمیم واقعی را نمایندگی نمی‌کنند. نشانی `example.org` نمونه است و ابزار آن را باز نمی‌کند.

فیلدهای `checked` و `verified`، سطح مطالعه و نقش‌های fixture، حالت‌های ساختگی برای آزمودن قراردادند؛ آن‌ها را به پروندهٔ واقعی کپی نکنید. وضعیت حریم خصوصی نمونه نیز یک مقدار آزمون است، نه انتشار اطلاعات یک پروژهٔ خصوصی.

اجرا از ریشهٔ مخزن:

```bash
node scripts/validation/validate-records.cjs --input examples/records/synthetic-bundle.json
```

کد خروج مورد انتظار `0` و وضعیت `valid` است. معتبر بودن این نمونه نشان می‌دهد ساختار و ارجاع‌ها سازگارند، نه اینکه ادعاهای بیرونی راستی‌آزمایی شده‌اند.

نمونه باید با سازندهٔ دادهٔ مصنوعی در `tests/fixtures/records.cjs` یکسان بماند؛ آزمون برابری محتوا در `tests/validator.test.cjs` اجرا می‌شود. میانگین نمونه در `tests/schemas.test.cjs` دوباره محاسبه می‌شود. مقدار را عوض نکنید و بدون بازبینی همان ادعا یا وضعیت قبلی را نگه ندارید.

برای دادهٔ واقعی، شرح پروژه و پرونده را بیرون این پوشه و با کنترل دسترسی مناسب نگه دارید. [راهنمای ابزار و محدودیت‌ها](../../scripts/validation/README.md) را بخوانید.
