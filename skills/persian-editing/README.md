# ویرایش فارسی، نسخهٔ 0.1.0

وضعیت: experimental. سه سطح نمونه‌خوانی، ویرایش زبانی محافظه‌کارانه و بازنویسی. این بسته دستور کار برای مدل است، نه برنامهٔ تبدیل یا اصلاح خودکار متن.

## استفاده

در مخزن کامل، از [دستور اصلی](SKILL.md) شروع کنید. ارجاع‌های مشترک در نسخهٔ منبع به استانداردها و پروفایل‌های ریشهٔ مخزن می‌روند؛ کپی‌کردن این پوشه به‌تنهایی کافی نیست. برای بستهٔ مستقل، از ریشهٔ مخزن اجرا کنید:

```bash
python3 scripts/packaging/build-skill.py --output dist/persian-editing-0.1.0.zip
```

خروجی یک پوشهٔ `persian-editing` در ZIP است، با دستور، چهار راهنمای موردی، دو پروفایل، سه استاندارد، مجوز، اعلان منابع و manifest منشأ. همهٔ ارجاع‌های محلیِ دستور ساخته‌شده در خود بسته حل می‌شوند. نسخه‌های همراه، خروجی ساخت‌اند؛ آن‌ها را جدا ویرایش نکنید. راهنمای ساخت و این README جزو محتوای زمان اجرای بسته نیستند.

برای ابزار پشتیبان Agent Skills، پوشهٔ استخراج‌شده را با روش همان ابزار بارگذاری کنید. برای محیط صرفاً متنی، دستور و منابعی را که لازم دارد در اختیار مدل بگذارید؛ وجود لینک محلی به معنی دسترسی مدل به فایل نیست. سازگاری یا نصب در هیچ محصول مشخصی هنوز آزموده نشده است. این مرحله هیچ اسکیل نصب‌شده‌ای را تغییر نمی‌دهد.

## آزمون و محدودیت

[مجموعهٔ سناریوها](../../tests/fixtures/editing-cases.json) ورودی‌های مصنوعی و معیارهای داوری دارد، نه پاسخ‌های مدل. [گزارش ارزیابی](../../docs/evaluations/persian-editing-0.1.0.md) آزمون ساخت را از ارزیابی رفتاری جدا می‌کند. امتیاز آشکارساز هوش مصنوعی معیار قبولی نیست.

درخواست متنی معمول به شبکه یا اجرای کد نیاز ندارد. فرایند ساخت برای نگهدارنده است؛ مدلِ ویرایشگر نباید آن را برای هر ویرایش اجرا کند.
