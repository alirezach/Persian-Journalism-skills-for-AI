# ویراستاری فارسی ۰.۲.۰

فقط ویراستاری فنی و زبانی، نه بازنویسی آزاد یا دیتاکس. وضعیت آزمایشی است. دستور اصلی در SKILL.md و چهارده راهنمای تخصصی در references قرار دارند؛ قواعد از گردآوری ارائه‌شدهٔ اصول ذوالفقاری اقتباس شده‌اند. اصل کتاب بررسی نشده و متن کامل آن بازنشر نمی‌شود.

برای «ویرایش کن»، مسیر زبانی محافظه‌کارانه انتخاب می‌شود. نمونه‌خوانی فقط اصلاح فنی است. اصلاح عمیق‌تر جمله با درخواست روشن مجاز است، اما تغییر استدلال، ساخت مثال و تغییر مخاطب در دامنه نیست. نقل‌قول، عدد، قید، کد و شناسه محافظت می‌شوند. گزینهٔ محدود تبدیل ی و ک در رونویسی مجاز همچنان پیش‌فرض خاموش است.

از ریشهٔ مخزن، با Python 3.10 یا جدیدتر:

```bash
python3 scripts/packaging/build-skill.py --output dist/persian-editing-0.2.0.zip
```

سازنده منابع مشترک، پروفایل‌ها و ابزار اختیاری را از مسیرهای تعیین‌شده همراه می‌کند؛ کپی پوشهٔ منبع به‌تنهایی جای بستهٔ مستقل نیست. بستهٔ ساخته‌شده شامل متن کامل دستور، همهٔ راهنماها و منابع لازم است. مسیرهای منابع در دستور بسته نسبت به ریشهٔ همان مهارت تفسیر می‌شوند.

نسخهٔ ۰.۲.۰ مسیر بازنویسی آزادِ ۰.۱.۳ را عمداً کنار می‌گذارد. شواهد و ZIPهای تاریخی حفظ می‌شوند، اما نتیجهٔ قبولی به این نسخه منتقل نمی‌شود. مهارت مستقل persian-ai-detox برای اصلاح الگوهای کلیشه‌ای است؛ persian-editing-and-ai-detox هر دو مهارت را کامل همراه دارد.

فقط آزمون‌های فنی و بسته‌بندی در این مرحله اجرا می‌شوند؛ مثال‌ها و سه درخواست پیشنهادی، ارزیابی مدل نیستند. نصب میزبان یا تأیید کیفیت عمومی انجام نشده است.
