# ویراستاری فارسی و دیتاکس، نسخهٔ ۰.۲.۰

نام مهارت `persian-editing-and-ai-detox` است و جای نام قبلی `persian-editing-detox` را می‌گیرد. این بسته، تمام محتوای دو مهارت مستقل را همراه دارد؛ راهنماهای کوتاه جای مهارت اصلی را نگرفته‌اند.

در مخزن، دستور به دو پوشهٔ اصلی ارجاع می‌دهد. هنگام ساخت، نسخهٔ کامل بسته‌های مستقل به components منتقل می‌شود و فقط مسیر ورودی داخلی از SKILL.md به INSTRUCTIONS.md تغییر می‌کند؛ متن دستور و سایر فایل‌ها کامل و بدون تلخیص باقی می‌مانند. هر مسیر درون یک مؤلفه نسبت به ریشهٔ همان مؤلفه تفسیر می‌شود. manifest بیرونی، نسخه، هش و نگاشت تک‌تک فایل‌ها را ثبت می‌کند.

برای درخواست «هر دو»، دیتاکس و ویرایش زبانی با حفظ معنا انجام می‌شوند و ویرایش فنی مرحلهٔ پایانی است. برای درخواست تک‌منظوره فقط همان مؤلفه خوانده می‌شود. دستور کوتاه مسیریابی مجوز کنارگذاشتن راهنماهای لازم نیست.

ساخت از ریشهٔ مخزن، با Python 3.10 یا جدیدتر:

```bash
python3 scripts/packaging/build-persian-language-suite.py --skill persian-editing-and-ai-detox --format standalone --output dist/persian-editing-and-ai-detox-0.2.0.zip
python3 scripts/packaging/build-editing-detox.py --format opencode --output dist/persian-editing-and-ai-detox-0.2.0-opencode.zip
```

فرمان قدیمی build-editing-detox.py فقط سازگارکنندهٔ ساخت نام جدید است؛ مهارت قدیمی را دوباره نصب یا عرضه نمی‌کند. برای مهاجرت، نسخهٔ نصب‌شده و تغییرات محلی را بررسی کنید و دو نام قدیمی و جدید را هم‌زمان برای یک کار فعال نکنید. هیچ فایل نصب‌شده یا تنظیم میزبان خودکار حذف یا عوض نمی‌شود.

بسته خودبسنده است، اما نصب و بارگذاری واقعی در میزبان آزموده نشده است. وضعیت آزمایشی، سناریوهای رفتاری اجرا‌نشده و محدودیت منابع هر دو مؤلفه حفظ می‌شوند. پوشش کامل مؤلفه‌ها به معنی بازنشر کامل کتاب یا تضمین کیفیت مدل نیست.
