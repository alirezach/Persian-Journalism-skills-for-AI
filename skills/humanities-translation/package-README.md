# بستهٔ آزمایشی ترجمهٔ علوم انسانی

نسخهٔ منبع: `0.1.0`؛ وضعیت: `experimental`؛ مرحلهٔ فایل توزیعی: `experimental`.

ارتقا به experimental در 2026-11-15 با تصمیم صریح صاحب پروژه انجام شد؛ این تصمیم مجوز استفادهٔ آزمایشی با بازبینی خروجی است، نه قبولی آزمون، تأیید انسانی یا سازگاری میزبان. بستهٔ قبلی با وضعیت planned جدا حفظ شده است. metadata با مقدار source-only در دستور اصلی به پیاده‌سازی راهنمای متنی اشاره می‌کند؛ ابزار ترجمه یا برنامهٔ اجرایی داخل بسته نیست.

## استفاده و محتویات

از [دستور اصلی](SKILL.md) شروع کنید. بسته باید با ساختار پوشه‌ها نگه داشته شود؛ راهنماهای موردی فقط هنگام نیاز خوانده شوند:

- [اصطلاحات](references/terminology.md)، [وفاداری](references/fidelity.md)، [متن بلند](references/long-text.md) و [مثال‌های تألیفی](references/examples.md)؛
- سه استاندارد مشترک وفاداری، حریم خصوصی و اختیار؛
- دو پروفایل فارسیِ نمایش و شیوه‌نامه؛
- [الگوی تصمیم‌های ترجمه](../../templates/translation-decisions.csv)؛
- [مجوز MIT](../../LICENSE)، [اعلان منابع](package-NOTICES.md) و فایل تولیدشدهٔ `manifest.json`.

مجموع خروجی ۱۵ فایل است. manifest مسیر مبدأ و مقصد، مجوز محتوای اصیل، هش ورودی و خروجی و بازنویسی پیوندها را ثبت می‌کند؛ هش خودش را در خودش ندارد. baseline_revision نسخهٔ مبنا پیش از این ساخت است؛ هش هر فایل مبنای تشخیص محتوای واقعی است، نه ادعای تعلق تمام ورودی‌ها به آن commit.

## محدودیت‌ها

کنترل مسیرها، فهرست مجاز و پیوندهای سادهٔ محلی بخشی از ساخت است، نه مجموعه‌آزمون یا ارزیابی ترجمه. پیوندهای نسبی از محل هر فایل حل می‌شوند. لنگر عنوان، نشانی بیرونی، صحت محتوا، کیفیت ترجمه، فعال‌سازی خودکار و سازگاری میزبان بررسی نشده‌اند. برای خواندن خود بسته نیاز به کد، اتصال شبکه یا نصب اسکیل ویرایش نیست؛ توانایی اجرای ترجمه به محیط میزبان بستگی دارد.

هیچ آزمون پروژه، تولید آزمایشی مدل، داوری یا نصب در آماده‌سازی این بسته انجام نشده است. مثال‌ها شاهد ارزیابی نیستند. برنامهٔ سازنده، فایل‌های خصوصی، پاسخ‌های کاربران، PDF منابع، قلم و کتابخانهٔ جانبی داخل ZIP نیستند. انتقال متن حساس و انتشار خروجی همچنان اختیار جدا می‌خواهند.

این فایل الگوی README خروجی است؛ سازنده فقط پیوندهای آن را به مسیرهای داخل بسته تبدیل می‌کند. فایل‌های منبع مخزن تغییر داده نمی‌شوند.
